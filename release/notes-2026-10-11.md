Unofficial OrangeFox R12.0 for **Google Pixel 4 XL (coral)**.

The About screen now identifies **Hecker** as maintainer and displays the Pixel 4 Series support URL. This source build replaces the default "Testing build (unofficial)" maintainer entry.

Maintainer: [Hecker (its-hecker)](https://github.com/its-hecker)
Support: [Pixel 4 Series](https://t.me/pixel4seriesofficial)

The recovery image was built from commit `6d3c046d8a33ff4194a1e9f17f835c3786c87767` in [run 38088385193](https://github.com/its-hecker/orangefox_device_google_coral/actions/runs/38088385193). The release tag records the publication configuration; `device-tree-commit.txt` records the image's source commit. Checksums, the source manifest and kernel provenance are included.

The previous image was tested on Coral with Infinity Android 17: boot, touch, ADB, MTP, PIN/data decryption, automatic battery percentage, settings, brightness changes and theme reload. The tester also reported successful ROM ZIP flashing and boot to Android, and a small file transferred in recovery remained visible after reboot. This build keeps the same functional configuration and adds maintainer/About details. It has passed structural, startup-configuration and packaged About checks; device testing of this new image remains pending.

Temporary boot on **coral**:
```sh
fastboot getvar product
fastboot boot OrangeFox-unofficial-coral.img
```

The [previous tested image](https://github.com/its-hecker/orangefox_device_google_coral/releases/tag/R12.0-coral-unofficial-20261010) remains available. Thanks to OrangeFox and TeamWin; original source notices are preserved.
